# Quira Browser Roadmap

> Last updated: 2026-03-28

## Phase 1: Foundation (Q2 2026)

### April 2026 — Alpha Internal
- [ ] Gecko fork with browser shell
- [ ] Context Spaces: create, switch, delete, drag-and-drop tabs
- [ ] Space Bar UI with environment color theming
- [ ] Classic layout (Chrome-compatible default)
- [ ] Command palette (Space switching + URL input)
- [ ] Dev Container / Nix Flake for one-command build

### May 2026 — Alpha + AI
- [ ] Local LLM integration (Phi-3.5 Mini via llama.cpp)
- [ ] Page summarization and entity extraction
- [ ] AI Shield privacy indicator (Local/Cloud toggle)
- [ ] MLX support for Apple Silicon
- [ ] Progressive Disclosure: Day 1 experience

### June 2026 — Alpha + Context Graph
- [ ] Context Graph engine (SQLite + vector embeddings)
- [ ] Side panel + full-screen graph views
- [ ] Natural language query in command palette
- [ ] Source-cited answers (zero hallucination)
- [ ] Graph filtering (date, domain, tags)
- [ ] "Wow Moment" onboarding (Day 3)
- [ ] Plugin API early preview

## Phase 4: Platform (2027+)

- [ ] Knowledge Templates marketplace
- [ ] Proof of Depth (verified expertise certificates)
- [ ] Context DNA (knowledge transfer)
- [ ] Mobile apps (Android / iOS)
- [ ] Quira Foundation establishment

## Principles

1. **Local-first, always.** Your data stays on your device by default.
2. **Progressive disclosure.** New features appear when you're ready.
3. **Open core.** Core browser experience is open source forever.
4. **Your data stays yours.** We will never monetize your browsing data.
